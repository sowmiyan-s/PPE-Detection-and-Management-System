# 🖥️ Cerberus AI Frontend — Executive Control Room SPA

> **Repository:** [https://github.com/Vidhyasree14/Cerberus-AI](https://github.com/Vidhyasree14/Cerberus-AI) | **Developer:** Vidhyashree M

The **Cerberus AI Control Room** is an industrial-grade Single Page Application (SPA) built for real-time edge telemetry visualization, multi-camera surveillance, incident triage, and worker compliance management.

---

## 🛠️ Technology Stack

| Technology | Role |
| :--- | :--- |
| **React 19** | UI component rendering with concurrent features |
| **TanStack Start** | Full-stack SSR/SPA framework with file-based routing |
| **TanStack Router** | Type-safe client-side routing with file-based route splitting |
| **Tailwind CSS v4** | Utility-first styling with curated industrial dark theme tokens |
| **Recharts** | Dynamic compliance trend graphs, live latency histograms, heatmaps |
| **Lucide React** | Consistent industrial-style iconography |
| **WebSocket API** | Real-time `WS /ws` telemetry frame receiver |
| **Fetch API** | RESTful data client with live polling hooks |

│   │   ├── reports.tsx       # Compliance Audit Reports (/reports)

## 🗺️ Dashboard Pages

| Route | URL | Description |
| :--- | :--- | :--- |
| **Executive Dashboard** | `/` | Fleet compliance rate, active violations, FPS throughput, 7-day trend |
| **Live Camera Wall** | `/live` | Multi-camera grid with bounding boxes, worker IDs, and focus stream zoom |

| **Model Telemetry** | `/model` | Live CPU/RAM/GPU monitoring, inference FPS, camera capacity estimator |

## 🚀 Development & Production Build

### Install Dependencies
```bash
cd frontend
npm install
```

### Start Development Server
```bash
npm run dev
```
Opens at **`http://localhost:5173`** with hot-module replacement.

The Vite proxy automatically forwards `/api/*` and `/ws` requests to the FastAPI backend at `http://localhost:8000`.

### Production Compilation
```bash
npm run build
```
Generates optimized client and server bundles in `.output/`.

### Run Production Build Locally
```bash
npm run start
```

## 🔌 Backend Connectivity

The frontend connects to the FastAPI backend at:

| Connection Type | Development | Production |
| :--- | :--- | :--- |
| **REST API** | Proxied via Vite (`/api/*` → `http://localhost:8000`) | Served through nginx reverse proxy |
| **WebSocket** | `ws://localhost:8000/ws` | `wss://your-domain.com/ws` |
