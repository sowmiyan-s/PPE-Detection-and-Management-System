# 🗺️ TanStack File-Based Routes Directory

This directory defines the page routes for the **Cerberus AI Control Room** using TanStack Router file-based route resolution.

---

## 📌 Route Mapping & Functionality

| Route File | URL Path | Operational Focus |
| :--- | :--- | :--- |
| `index.tsx` | `/` | Executive platform overview, daily compliance rate, and fleet metrics |
| `live.tsx` | `/live` | Multi-camera surveillance grid with focus stream zoom and live bounding boxes |
| `violations.tsx` | `/violations` | Real-time incident inbox for verifying, accepting, or declining safety alerts |
| `compliance.tsx` | `/compliance` | Per-worker compliance scorecards, visual proof gallery, and selective violation removal |
| `zones.tsx` | `/zones` | Per-zone PPE requirement rules and temporal debounce thresholds |
| `cameras.tsx` | `/cameras` | Registration and health monitoring of RTSP, USB webcam, and video streams |
| `reports.tsx` | `/reports` | Safety telemetry audits with PDF and Excel export capabilities |
| `model.tsx` | `/model` | Live hardware performance (CPU/RAM/GPU), extra webcam capacity estimator, and real class statistics |

> **Note:** `routeTree.gen.ts` is automatically generated by TanStack Router. Do not modify it manually.
