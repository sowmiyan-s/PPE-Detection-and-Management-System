# 🗺️ TanStack File-Based Routes Directory

> **Repository:** [https://github.com/Vidhyasree14/Cerberus-AI](https://github.com/Vidhyasree14/Cerberus-AI) | **Developer:** Vidhyashree M

This directory defines the page routes for the **Cerberus AI Control Room** using TanStack Router file-based route resolution.

---

## 📌 Route Mapping & Functionality

| Route File | URL Path | Operational Focus | Key Features |
| :--- | :--- | :--- | :--- |
| `index.tsx` | `/` | Executive Dashboard | Fleet compliance rate, active violation count, 7-day trend graph, camera fleet status |
| `live.tsx` | `/live` | Multi-Camera Surveillance | Real-time bounding boxes, `Worker-ID` tracking badges, focus stream zoom, zone selector |
| `violations.tsx` | `/violations` | Incident Triage Inbox | Accept / decline alerts, full-res evidence modal, bulk delete, multi-criteria filters |
| `compliance.tsx` | `/compliance` | Worker Compliance Gallery | Per-worker scorecards, photo timeline, selective violation purging, compliance recalculation |
| `zones.tsx` | `/zones` | Zone PPE Rules | Per-zone PPE requirements, temporal threshold (frame window + dwell) configuration |
| `cameras.tsx` | `/cameras` | Camera Stream Manager | Register RTSP / USB / MP4 sources, health monitoring, camera deletion |
| `reports.tsx` | `/reports` | Compliance Audit Reports | Date-range filtering, CSV/Excel export, trend charts, per-zone heatmaps |
| `model.tsx` | `/model` | Hardware Telemetry | Live CPU/RAM/GPU gauges, inference FPS, P95 latency, extra camera capacity estimator |
| `test.tsx` | `/test` | Development Sandbox | Internal development and UI testing route |
| `__root.tsx` | *(layout)* | Application Shell | Sidebar navigation, top bar, route outlet wrapper |

---

## 📝 File Notes

- **`routeTree.gen.ts`** — Automatically generated by TanStack Router's file-based route scanner. **Do not edit manually.** Regenerated on every `npm run dev` startup.
- **`__root.tsx`** — The root layout wrapping all pages. Contains the `<AppShell>` sidebar and top navigation bar.
- **`test.tsx`** — Internal development route not linked in the production navigation sidebar.
